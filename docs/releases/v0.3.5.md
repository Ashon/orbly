Your other AI tools can read what Pace did, and Pace's mark now moves while it works.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

## Run history for AI tools

Claude Code, Codex and other MCP tools on your Mac can now read Pacenote's run history: recent runs, a search, and one run
with each tool call, its result and the answer. Turn on **Settings > History & logs > Share with AI tools**, then add
Pacenote to the tool with the command that card shows. It is off by default and read-only, runs with the app's own Node
(no install, no port), redacts secrets, and stops at once when you turn it off. See
[Run history for AI tools](../history-mcp.md).

## Pace at work

- While a run is in progress, its timeline shows Pace's mark looking around where the answer will appear.
- The Pace screen shows it while Pace starts, builds or stops, and pairing with a team hub shows it while Pace waits for
