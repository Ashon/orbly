The assistant is now Pace. You drive. Pace reads the notes.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

## Pace

Pacey is now Pace: the bot's answers, the app, the draft PR signature and the pairing message (`@Pace connect <code>`)
use the shorter name. Settings, paths and the `PACENOTE_*` keys stay the same.

For Slack to show the new name, set the bot's display name to Pace in api.slack.com > your app > App Home, or re-apply
`slack-app-manifest.yaml`. A team hub's Slack app gets the same; the hub image itself is unchanged. The bot's handle
stays the one it got when the app was first installed, and mentions show the display name.

## Also in this release

- Each reasoner CLI is now an adapter (`src/reasoners`) and where it runs is a sandbox (`src/sandbox`: your Mac or a
  Docker container), so another CLI or another kind of isolation can be added without touching the rest. Answers work
  as before.
- The README is a short introduction and install guide; the rest moved to `docs/`, with the design in five diagrams.
- The cask's caveat names the Orbly and Verda homes Pacenote keeps using.
