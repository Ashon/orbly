Get the sandbox's claude token from your Claude subscription in one step.

```sh
brew upgrade --cask orbly
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests,
and the rest resume on the next start) and reopens it. Config and run history are untouched.

## Claude token for the sandbox

- Settings > Sandbox > Reasoner login has a "Get token from Claude" button when the reasoner runs
  in the Docker sandbox with the claude CLI. Orbly runs `claude setup-token`, you approve in the
  browser, and the one-year token is saved for the sandbox without being shown or copied.
- With a token already saved, the button reads "Get new token" and replaces it.
- The token belongs to your own Claude subscription (Pro, Max, Team or Enterprise). To keep the
  bot to your own requests, put your Slack user ID in Settings > Slack > Allowed users, or use
  the team hub, where each member's desktop answers only that member.
