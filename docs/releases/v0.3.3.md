A new layout: one surface for each screen, beside a sidebar that names its sections.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

## Layout

- The sidebar lists Overview, Runs and Pace at the top, and Settings at the bottom above Pace's status (connection,
  reasoner, last request, check issues). Cmd+B keeps only its icons, as do windows under 900 pixels.
- Each screen is one surface. Its parts are split by space and thin lines instead of cards of their own.
- Runs is its own section: the list and the selected run side by side, with a line between them you can drag
  (double-click resets it). In a narrow window it shows one at a time, with a way back to the list. Typing a search
  opens Runs.
- The selected item reads clearly in light mode, and selected buttons in segmented controls (the theme, the run filter)
  now show in dark mode.
- Overview is titled Overview, like the other screens.
