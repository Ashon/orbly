```sh
brew update && brew upgrade
```

The tap renames the `orbly` (and `verda`) cask to `pacenote`, so the upgrade quits Orbly (the bot gets up to 20
seconds to finish its requests, and the rest resume on the next start) and installs Pacenote.app in its place. New
installs use `brew install --cask pacenote`. If brew keeps listing `orbly`, run
`brew uninstall --cask orbly && brew install --cask pacenote`.

## Orbly is now Pacenote

In rallying, the co-driver reads pace notes so the driver can keep their eyes on the road. Pacenote is the project
and the app; Pacey is who you talk to: the Slack bot you mention and the voice of the app, which answers in the first
person ("Working on it..."). The app has a new mark, the earlier ring opened like a track with Pacey one step ahead.
The repository moved to [Ashon/pacenote](https://github.com/Ashon/pacenote), and old links redirect.

Your setup keeps working:

- While `~/.pacenote` does not exist, Pacenote uses `~/.orbly`, or else `~/.verda`, as it is, and `ORBLY_*` and
  `VERDA_*` settings are read as their `PACENOTE_*` names. The bot log says so, with how to move: stop the bot,
  `mv ~/.orbly ~/.pacenote` (or `~/.verda`), rename the old keys in `.env`. Nothing is moved for you.
- An old Verda or Orbly and the new Pacenote never run a bot at the same time; each sees the others'.
- Run history and logs from Verda and Orbly show as they are.

After upgrading:

- The sandbox images and containers are now named `pacenote-*`. In Settings > Sandbox, run "Build sandbox images"
  and "Restart proxy" (and "Recreate broker" if you use ops tools). The old `orbly-*` images and containers can then
  be removed. If your `.env` names `orbly-reasoner`, `orbly-renderer` or `orbly-sandbox`, remove those lines first.
- In api.slack.com, re-apply `slack-app-manifest.yaml` (app name Pacenote, bot display name Pacey), so mentions read
  `@Pacey`. A team hub needs the same for its Slack app, and a new hub image (`pnpm hub:image` builds `pacenote-hub`).
- Ops tools: new code changes go to `pacenote/*` branches; `orbly/*` and `verda/*` ones are still the agent's. The
  k8s account now defaults to `pacenote-ro` (`sandbox/k8s/pacenote-ro.yaml`); set `OPS_K8S_SA` to keep an old one.

## Also in this release

- Settings > Messengers: the chat apps the bot answers in, each under its own heading with how it is connected
  (Slack today). The bot reaches them through a messenger interface, so other chat apps can be added as adapters.
- Secret inputs (Slack tokens and the rest) have a Save button beside them: Enter saves just that value and closes
  the input. A setup can be saved a piece at a time; settings that are only missing no longer block saving.
- The menu bar menu opens with "Open Pacenote".
- End-to-end tests run the bot and the team hub against a local Slack stand-in, with coverage, on every push.
- `SLACK_API_URL` points the bot and the hub at another Slack Web API, such as GovSlack.
- A token Slack rejects ends the bot with "Startup failed" in its log, so the app shows "Setup needed" with the reason.
