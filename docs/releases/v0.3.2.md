Releases come from a new pipeline. The app is unchanged.

```sh
brew update && brew upgrade --cask pacenote
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests, and the rest resume on
the next start) and reopens it. Config and run history are untouched.

- Release builds are signed, notarized and published outside this repository. What you install is the same: a signed
  and notarized Pacenote.app, one zip per arch.
- `pnpm package:mac` builds an ad-hoc signed app for this Mac only.
