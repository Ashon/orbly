Settings in clear sections, and a bot that waits for setup instead of crashing.

```sh
brew upgrade --cask verda
```

The upgrade quits the running app first (the bot gets up to 20 seconds to finish its requests,
and the rest resume on the next start) and reopens it. Config and run history in `~/.verda` are
untouched.

## Setup needed, not "Crashed"

- Before launching the bot, the app checks the settings with the bot's own rules. On a first run
  without Slack tokens, or with an invalid value, the bot shows "Setup needed" and is not launched,
  instead of starting, exiting, and being reported as crashed.
- Tokens Slack rejects (`invalid_auth` and the like) also lead to "Setup needed".
- Other early exits show "Failed to start" with the cause and the last output. Only a bot that ran
  for 30 seconds or more shows "Crashed" and restarts on its own.
- The Bot screen, the Overview, the status bar and the menu bar offer "Open Settings" while setup is
  needed, and it opens the section to fix. Saving there starts the bot ("Save and start bot").

## Settings in sections

- Settings has its own section list: Slack, Answers, Sandbox, Ops tools, and History & logs for the
  bot, then General for the app.
- The list shows what needs attention: "Not connected" without Slack tokens, "Apply needed" for
  changes the sandbox or broker has not picked up, "Off" for features not in use, and per section
  the unsaved changes or a red dot for values to fix. Changes in several sections are saved together.
- The run environment is now the first choice in Sandbox ("On this Mac" or "Docker sandbox"). Sandbox
  limits show only for docker, and only the selected reasoner's login is asked for.
- Ops tools lists what it needs (the docker sandbox, allowed users) with links to fix them, and each
  integration (files, GitHub and pull requests, Jira, Kubernetes, SSH hosts) has a card marked On,
  Incomplete or Off, next to what the running broker reports.
- Theme, starting the bot with the app, and the settings file and run history folder are under
  General.
